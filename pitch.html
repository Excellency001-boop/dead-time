§01
The law

The clock is real, not a timer

The world moves if and only if real tokens are arriving.

There is one value, energy. Exactly one thing raises it: a real token streamed from a real model. Every frame it only ever drains. The clock that drives every shader and every sound reads from it. Stop the model and the universe stops with it.

# energy model — the whole honesty, in four lines on each real token energy += 0.15 // capped at 1.35 every frame, always energy *= 0.912 // no tokens -> decays to 0 void clock advances only while energy > 0 therefore motion ⟺ tokens arriving

No idle loop. No fake breathing. No timer faking the middle. A judge who realises "this only moves while my model is thinking" is a judge who remembers Dead Time.

§02
The loop

Five beats, one wait

01EnterPure black. Type a thought. Your letters appear as light. Release it into the dark.
02IgniteThe first real token lands. The void flares. Time turns on, and you hear it turn on.
03GatherFilaments drift out of the fog. You hold and pull them into one object. It grows with every token.
04FreezeThe answer returns. A shockwave rings out, the fog drains cold, your light locks into a crystal. Silence.
05CarryOne gesture pulls the crystal out of the void into reality. It joins your shelf of kept waits.
§03
The thesis

Waiting becomes value

A working demonstration of the Commons idea, felt from the inside.

Attention → substanceYour wait is the raw material. The longer and denser the inference, the richer the object you can make.
Compute → held objectThe object is a receipt of real inference, minted from the tokens the machine produced. How long you waited is baked into its shape and seed.
Value → persistentCarry an object out and it survives across sessions on your reality shelf. The wait produced a thing, and the thing is yours. The seed of Build2Earn.
Rail → x402 / USDCEach object is a discrete, ownable artifact tied to one real compute event. Exactly the shape you settle or account for in compute credits.
§04
Honesty

What is real, what is not yet

I would rather tell you than have you find it.

Real today

  • The honest clock and the live token stream from a local model.
  • The full loop — ignite, gather, freeze, crystallize, carry out.
  • The shelf that persists your kept waits across sessions.

Not yet

  • Money settlement. Takes no card, moves no funds, on purpose. The value is real and ownable; the rail is the next step.
  • Demo mode shows a clearly labelled simulated wait, never dressed up as real inference.
§05
Run it

No card · no cloud · one file

Runs on a local model through Ollama. Vanilla WebGL, Canvas, and synthesized Web Audio. Nothing external to fetch. Two terminals.

// let the browser reach the model
$ OLLAMA_ORIGINS=* ollama serve
// serve the void
$ cd dead-time/app && python3 -m http.server 8080

Open localhost:8080, click once, type a thought, press Enter. First run only: ollama pull llama3.2:1b. Show it without a model with ?demo=1. The readout along the bottom is the proof the clock is real. Watch it die when the answer lands.

If the freeze beat lands, you have already won the room.
